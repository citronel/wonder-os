# Wonder OS — Lumen

A mobile-first glass operating system prototype built with React, TypeScript, Vite, Three.js, and React Three Fiber. This project explores an immersive "Lumen Core" experience with layered transparent materials, real-time glass controls, and a polished OS-like interface.

## Features

- Real 3D glass core with transmission and reflective material treatment
- Immersive UI with glass panels and layered controls
- Lumen home screen with live time, widgets, and dock
- Functional calculator, notes, clock, music, gallery, and system information
- Local persistent notes and preferences
- Mobile-first design with touch-friendly interactions
- Cloudflare Pages-ready build configuration

## Run locally

npm install
npm run dev

## Production build

npm run build

## Cloudflare Pages

Build command: npm run build
Output directory: dist
